## AI Usage Statement

I used AI tools as a **supportive assistant** during this project, mainly to help me think through ideas and present them clearly. My primary use of AI was for **organizing and structuring documentation** so that explanations were concise, readable, and well-formatted.

AI was also used occasionally to:- Clarify general system design concepts,Validate standard approaches,Improve wording and flow in documentation.

All **core implementation work**, including system design, API structure, timezone handling, conflict detection logic, and coding, was done by me. I reviewed and understood every AI-assisted suggestion before using it and adapted it to fit the project requirements.

Overall, AI helped improve **clarity and presentation**, but the problem-solving, design decisions, and final implementation reflect my own work and understanding.
